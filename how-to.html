The basic workflow

Choose Source→Preview→Rename→Choose Destination→Move + Next

1. Choose the Source folder

Select a saved Source, type a folder path, or use Browse. Use Sources… to save folders you clean regularly. DCM validates a typed path before switching to it.

2. Narrow the inbox

Use Type, Extension, Name, Age and Size filters when a folder contains many files. Clear Filters restores the full inbox.

3. Select and preview

Click a file in the Files list. DCM previews supported formats in the center so you can identify the file before changing its name or location.

4. Give it a useful name

Edit the Name field while the content is visible. Rename tools can clean spacing, change case, add a date prefix, or apply a template. The extension stays protected.

5. Choose the Destination

Select a saved Destination alias or choose a path. The complete destination path remains visible before anything is moved.

6. Rename + Move + Next

Press Rename + Move + Next only when the proposed name and destination are correct. DCM moves the file and advances to the next item.

PDF preview controls

PDFs use DCM's own Windows PDF preview path rather than relying on the Edge preview handler.

Fit

Fits the current PDF page inside the preview area.

100% and zoom

Use 100%, +, −, or Ctrl+mouse-wheel. Manual zoom supports 25–800%.

Pages and pan

Use Previous/Next for multi-page PDFs. When zoomed in, drag the page to pan around it.

Undo, Recovery and safety

Processed

Completed moves appear in Processed. Select the transaction you want and use Undo to reverse that specific move when it is still safely reversible.

Recovery

DCM journals file-changing operations. If a copy or replacement is interrupted, Recovery can explain the state and offer safe recovery actions instead of guessing.

Cross-volume moves

On the same volume DCM normally uses a fast rename/move. Across volumes it copies, verifies the destination, and only then removes the source.

Learning and suggestions

DCM can learn locally from completed rename and destination choices. Learning does not upload file contents or use cloud AI. When enough evidence exists, Suggestion can propose a destination or reproducible rename style. Applying a suggestion edits the fields only; Rename + Move + Next remains the commit action.

A good first session

Start with a messy Downloads or scanner folder. Do not try to organize everything perfectly before you begin. Pick one file, preview it, name it clearly, choose where it belongs, move it, and repeat.

DCM works best when the next decision is easier than opening the file manually.
