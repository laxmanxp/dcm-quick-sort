## What the tests establish

| Boundary | Verified behavior |
| --- | --- |
| Source contents change after copying | Both plain and progress workers refuse source deletion, including a same-size edit with the old modification time restored. |
| Another file replaces the source path | Identical bytes do not substitute for original file identity; the old original, replacement source and copied destination are retained. |
| Destination changes or has an open writer | Source deletion is refused; the tests independently read retained bytes. |
| Recovery uses outdated verification | A source edited at copy completion or after prior Finish inspection is retained, and its journal entry remains `attention`. |
| Competing writer, rename or delete while guarded | Windows read and retirement guards deny those operations. The positive owned-handle deletion case also executes successfully. |
| Final-component symbolic link | The link fixture executes rather than skipping; source, target and link remain after refusal. |
| Partial-copy cleanup | Changed target identity, target bytes, source bytes or an unverified prefix prevents removal; fixture contents remain intact. |
| Occupied destination | DCM-06's no-overwrite test remains PASS, preserving both original hashes. |

The plain/progress worker tests additionally require an error, `BackgroundMoveCopiedSourceRetained`, and no successful `MoveRecord`. They do not treat a completed copy as proof of a completed move.
