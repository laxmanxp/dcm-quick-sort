## Application scope

DCM QuickSort is the standalone Windows application for previewing, renaming, moving files into the Vault, and recovering or undoing file operations. FileFlowSuite, Flow Search, DeepSearch and FileFlow retain their separate application/window scope. This candidate completes work on the recovered DCM implementation and its existing Windows PDF preview path. It does not establish feature parity with a Walk UI migration or certify a FileFlow printing change.
